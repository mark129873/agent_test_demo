# 晚灯 · 文字陪伴 Demo

阿晚是一个虚构的成年角色。这是面试题的第一阶段：文字聊天、长期记忆、改期更新和主动回访。不包含语音、照片、视频或数字人渲染，不是原题全部功能。

## macOS 启动

需要 Python 3.11 或 3.12。打开「终端」，进入刚解压或克隆的项目目录：

```bash
cd /你的路径/agent_test_demo
python3 --version
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
```

如果 `python3` 不是 3.11 或 3.12，请用对应的 `python3.11` 或 `python3.12` 创建虚拟环境。然后在 Mac 浏览器打开 http://127.0.0.1:8765/ 。用 `Ctrl+C` 停止后端；下次只需在项目目录执行 `.venv/bin/python app.py`。记忆会保存在 `companion.sqlite3`。仅本机、单用户、单进程运行，不要直接暴露到公网。

默认是**离线模拟**，不需 Key、不调用模型。模拟模式是演示测试数据流的轻量规则，不代表真正的理解或模型回复质量。真实聊天：打开「设置」，配置 OpenAI 官方 API 地址、账号可用的模型名（默认 `gpt-6-luna`）和自己的 Key，手动切换到 OpenAI。模型须支持 Chat Completions JSON 模式。真实请求会把本轮内容和相关上下文发往 OpenAI，且可能计费。Key 不回显、不落盘；重启可重新输入，或在启动前把 Key 放到 `OPENAI_API_KEY` 环境变量里。打包文件没有 Key 或数据库。

## 现场验收

1. 发「我不吃香菜，我养了一只猫叫年糕，我住北京，下周三面试。」
2. 发「我从北京搬到上海了，面试改到下周五。」
3. 从「记忆」看原话来源，确认现居地是上海，面试只保留新日期。重启服务，再打开，记忆和对话仍在。
4. 在「设置 → 演示工具」选原面试日的次日，确认不会按老日期回访；再选新日期的次日，收到一条问候。再次模拟同一天，不重复问。测试日期只影响回访，不改变系统或记忆时间。要重复整套演示，可在终端设置 `COMPANION_DB` 指向一个新的本地数据库文件再启动。
5. 切到 OpenAI 但留空 Key，可测试错误提示和重试按钮；聊天历史和记忆仍可查看。再切回模拟模式重试，无需付费。

## Agent 设计

- `agent.py`：角色卡、OpenAI 适配、离线模型、相关记忆选择、候选校验与相对日期解析。
- `app.py`：FastAPI、SQLite 和两个触发器。收到消息时在同一次模型调用获得回复和候选记忆。只有用户消息可写入记忆；用稳定的记忆键更新事实和事件。打开页面时只在有到期事件的情况下请求问候，问候与状态更新同一事务提交。
- `static/`：聊天、记忆、设置。使用文本节点渲染消息，不把聊天内容当 HTML。
- `tests/`：模拟端到端、错误及配置测试。运行 `python -m unittest discover -s tests -v`，不产生模型费用。

## 本轮产品经理复审

独立评审两次打回：问句或假设不应覆盖事实；改简历不应更改面试；带日期的取消要终止回访；对结果的担心并不等于结果已发生。修正后第三轮通过纯文字离线范围，并改了角色开场、示例填入、问候标识和手机布局。现有离线测试通过；真实 OpenAI 回复和手机浏览器视觉/软键盘没有验收。仅对最近 14 天已经结束的事件进行自动回访，避免隔几个月突然追问。每类记忆键存当前值，同名事件用一个槽位；不支持同时追踪多个同名面试。
